# M7 狀態報告：全螢幕刷題介面 + 圖片顯示優化

> 日期：2026-08-16
> 階段：M7 全螢幕單題刷題 + kitty 真彩圖片 — 已完成

## 1. 目標

把原本「打字作答」的刷題改為**全螢幕單題一頁**的互動介面（上下箭頭選擇），並解決圖片顯示的清晰度與穩定問題。

## 2. 實現

### 2.1 全螢幕單題刷題（`trainer/tui.py`）
- 每題以一個全螢幕頁面呈現：**題目與選項靠左、帶青色橫線分隔，圖片在上方**。
- 上下箭頭 `↑`/`↓` 移動選擇，`Enter` 確認作答，`q` 退出。
- **錯題重答**：答錯顯示「答錯（請重答）」並給一次重答機會，正確答案高亮，再錯才下一題。
- 增量重繪：圖片只渲染一次，移動選項只重寫該項，不整頁重建，避免畫面錯亂。

### 2.2 圖片顯示
- 改回 **kitty icat 真彩原圖**（原曾試 chafa 半塊畫，因像素化被否）。
- 圖片以 **convert 插值放大**後顯示較大小、仍清晰；放大結果**快取**至 `data/images_cache/`，二次顯示免重複處理。
- 圖片寬度與題目區對齊、每張固定大小；底部與題目橫線預留間隔避免壓線。

### 2.3 布局打磨（多次迭代）
- 去掉左右豎線（對齊不穩），只用橫線分隔；行距加大、橫線佔滿整行。
- 圖片高度自適應終端，確保底部橫線不入屏外、不被裁剪。
- 全螢幕倒計時大字（結合 M8 的 `edata`）。

## 3. 驗證

- 答對 / 答錯重答流程（pexpect 實測）：`r`→prev、Enter→next、q→quit 均正確。
- 圖片放大與快取：首次 convert 生成、二次命中快取（0.000s），源圖變更才重生。
- 布局：橫線滿寬、題目選項靠左、圖片居中、每張固定大小、不超屏、不壓線。

## 4. 交付物

- `trainer/tui.py`：全螢幕單題刷題（含 learn 學習模式渲染）。
- 圖片放大 + 快取機制（config 加 `IMAGE_CACHE_DIR`）。

## 5. 說明 / 遺留

- 圖片實際清晰度受源圖解析度限制（原圖約 165px）；convert 插值減少鋸齒，但非矢量放大。
- 快取目錄不入版控（`.gitignore`），可刪除重建。
