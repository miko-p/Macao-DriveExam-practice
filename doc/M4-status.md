# M4 状态报告：数据能力（错题重练 + 成绩统计）

> 日期：2026-08-16
> 阶段：M4 数据能力 — 已完成

## 1. 目标

让练习数据产生价值：错题本重练、正确率统计、分章节成绩总览。

## 2. 实现

### 2.1 数据层（`database/store.py`）
- `get_wrong_questions()`：查答错过且正确率 <100% 的题（可限章节 / 最少作答次数）。
- `overall_stats()`：整体题数、已作答、正确率、错题占比。
- `stats_by_subject()`：按章节汇总题数/已作答/正确率。

### 2.2 练习端（`trainer/main.py`）
- `--mode wrong`：错题重练，只取错题本里的题。
- `--mode stats`：成绩统计，rich 表格显示整体 + 分章节正确率。

## 3. 验证（真实 647 题数据 + 真实作答记录）

- wrong 模式能正确列出并重练曾经答错的题。
- stats 模式显示 647 总题数、已作答数、整体正确率、分章节正确率，表格渲染正确。
- 作答流水正确反映对错（正确率 = Σcorrect / Σattempts）。

## 4. 交付物

- `database/store.py`：错题集 / 整体统计 / 分章节统计查询。
- `trainer/main.py`：wrong、stats 两个模式。

## 5. 说明 / 遗留

- 暂未做「按错题次数优先」的排序加权（当前按题号序），可后续优化重练优先级。
- 作答时间粒度（日期/会话）的统计可后续加。
