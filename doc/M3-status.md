# M3 状态报告：练习端基础（顺序/随机/章节刷题）

> 日期：2026-08-16
> 阶段：M3 练习端基础 — 已完成

## 1. 目标

实现交互式 CLI 刷题，从 SQLite 读题、逐题作答、即时对错反馈，并把作答记录写入 `practice_log`。

## 2. 实现（`trainer/main.py`）

- 用 **rich** 做终端 UI：`Panel` 显示题目卡片（章节 + 题号 + 题干 + 选项），彩色对错反馈。
- 命令入口：
  ```
  python -m trainer.main                    # 全部章节，顺序刷题
  python -m trainer.main --subject 第一冊   # 指定章节
  python -m trainer.main --mode random      # 随机抽题
  ```
- 作答交互：输入 `A/B/C/D`；`q`/`quit` 退出；`s` 跳过（计入错）。
- 即时反馈：答对显示「✓ 正确」（绿色），答错「✗ 错误 答案: X」（红/绿双色）。
- 作答写入 `practice_log(qid, correct, mode)`，供 M4 统计与错题使用。
- 题目图片：题干含 `[img:相对路径]` 标记（相对项目根，可移植），终端中提示本地路径（或后续 kitty ascii 内嵌）。

## 3. 验证（真实题库数据）

- 顺序模式逐题显示正确，选项 A-D 完整，批改即时。
- `practice_log` 正确记录对/错与模式。
- 非交互（管道喂入 A/B/C）运行不崩溃，Ctrl+C 可优雅退出。
- 题库为空时给出友好提示。
